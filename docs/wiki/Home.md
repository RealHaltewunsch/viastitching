# ViaStitcher User Manual

This manual describes the **0.4.0 development branch**, based on upstream 0.3.4.
It is not documentation for a published 0.4.0 release. Spiral, Maximize, live
preview and segment centering described here are development features.

ViaStitcher places stitching vias in an existing filled copper zone. It uses the
net and dimensions you select, and offers several placement patterns. Always
run KiCad's Design Rules Checker after changing the board.
